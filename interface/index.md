# Interface

This section explains how the Launchpad grid is organised and how you move around it.

- [Pad map]({% link interface/pad-map.md %}): every pad area, the top row and the track column.
- [Modes and pages]({% link interface/modes-and-pages.md %}): the EDIT sub-modes, their pages, the hold-EDIT picker and the arrows.
- [Held pads and undo]({% link interface/held-pads-and-undo.md %}): SHIFT, LOCK, LOOP, DUP, CLEAR and the undo and redo gestures.

Pad numbers in this manual are the ones the app uses in programmer mode. Every grid pad is numbered, and the diagrams show those numbers.
