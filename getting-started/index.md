# Getting started

Work through these four pages once, in order. After that you will mostly use [Basic operation]({% link getting-started/basic-operation.md %}) and the [Interface]({% link interface/index.md %}) section.

1. [Installation]({% link getting-started/installation.md %}): unpack the program and find its data folder.
2. [MIDI setup]({% link getting-started/midi-setup.md %}): connect the Launchpad and the Circuit Tracks.
3. [First launch]({% link getting-started/first-launch.md %}): what happens when the app starts.
4. [Basic operation]({% link getting-started/basic-operation.md %}): the gestures everything else is built on.
